* ``go.m``: GNU Octave script for processing all Phase Station files, read using ``read_tim.m``
* ``mmcm_pure.tim``: MMCM output, no correction (Phase Station)
* ``mmcm_sd.tim``: MMCM with Sigma-Delta interpolation (Phase Station)
* ``mmcm_nl.tim``: MMCM with non-constant phase shift correction (Phase Station)
* ``mmcm_nl_sd.tim``: MMCM with Sigma-Delta and non-constant phase shift correction (Phase Station)
* ``mmcmoutoffilter.nse``: DNA
* `` mmcmpure.nse``: DNA
